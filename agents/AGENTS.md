# Global instructions

## Version control

- Never commit code unless the user explicitly requests it in the current request.
- Never push to a remote unless the user explicitly requests it in the current request.
- Never create or update a pull request unless the user explicitly requests it in the current request.
- Prior approval does not apply to later changes. Ask when the request is unclear.
- Never add agent attribution to commits, pull requests, or their messages.

## Writing style

- Never use an em dash. Use a comma, colon, parentheses, or separate sentences.
- Use ASD-STE100 Simplified Technical English.
- Write simply. Avoid decorative, vague, or overly formal language.
- Follow these principles:
  1. Simplicity: remove words that do no work.
  2. Brevity: use the fewest words that preserve the meaning.
  3. Clarity: keep one idea in each sentence.
  4. Humanity: write naturally from one person to another.
